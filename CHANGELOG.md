# Changelog

All notable changes to Ordexa Lite are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions
follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-08

Initial release — the free core of Ordexa Pro v1.4.0.

### Added

- E-commerce dashboard: KPI stat cards with trends, revenue area chart with
  7/30/90-day ranges, recent-orders table with sorting.
- Configuration-driven sidebar + ⌘K command menu from one typed config.
- Collapsible sidebar (icon mode, mobile drawer, cookie-persisted state),
  sticky glassmorphism header, dark/light mode.
- Generic strictly-typed `DataTable` on TanStack Table v8.
- Colorblind-validated chart palette, stepped per theme.
- `/login` with react-hook-form + Zod validation.
- Styled 404, error boundaries, streaming skeletons.
